# 🐾 Patitas Solidárias

Projeto desenvolvido para apoiar a adoção e o apadrinhamento de animais utilizando HTML, CSS e JavaScript.

## Funcionalidades

- Navegação SPA
- Cadastro de padrinhos
- Exibição de animais
- Validação de formulários
- LocalStorage
- Interface responsiva

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
